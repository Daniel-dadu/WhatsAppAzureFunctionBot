# Reporte de resultados del bot de WhatsApp de AlphaC

## Resumen

Se analizaron **31 conversaciones** disponibles en los meses de julio y
agosto de 2026. Los resultados combinan la información almacenada en el bot con
la validación manual de las cotizaciones enviadas.

| Métrica | Total |
| --- | ---: |
| Prospectos usuarios finales | **11** |
| Prospectos distribuidores | **12** |
| Prospectos sin clasificación | **8** |
| Conversaciones útiles | **29** |
| Conversaciones no útiles | **2** |
| Conversaciones completas | **7** |
| Conversaciones incompletas | **24** |
| Conversaciones donde el bot mostró el precio público | **2** |
| Conversaciones donde el bot envió la cotización en PDF | **2** |

## Definiciones

- **Usuario final:** requiere el equipo para uso propio o de su empresa.
- **Distribuidor:** se dedica a vender, rentar o distribuir maquinaria.
- **Sin clasificación:** no se obtuvo información suficiente para identificar
  el tipo de prospecto.
- **Conversación útil:** permitió identificar una necesidad comercial o avanzar
  en la calificación del prospecto.
- **Conversación no útil:** no reunió información comercial suficiente.
- **Conversación completa:** el bot obtuvo todos los datos necesarios para la
  ruta del prospecto y llegó al cierre correspondiente, como cotización,
  seguimiento o atención de un asesor.
- **Conversación incompleta:** el prospecto abandonó o no terminó el flujo.
- **Precio público mostrado:** el bot presentó directamente el precio de una
  máquina.
- **Cotización en PDF enviada:** el bot generó y mandó el documento de cotización
  al prospecto.
- **Distribuidor canalizado:** el bot le indicó que un asesor lo contactaría para
  continuar con su atención comercial.

## Lectura de negocio

- **23 de 31 prospectos** pudieron clasificarse como usuarios finales o
  distribuidores.
- **29 de 31 conversaciones** generaron información útil para seguimiento.
- **7 de 31 conversaciones** completaron el flujo.
- En **2 conversaciones**, el bot completó el proceso comercial mostrando el
  precio público y enviando la cotización en PDF.
- A **12 distribuidores** se les indicó que un asesor lo contactaría para continuar
  con la atención.
- Los clientes finales que no recibieron una cotización en PDF no compartieron
  todos los datos solicitados para poder generarla.
